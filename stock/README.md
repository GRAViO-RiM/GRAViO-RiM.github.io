# GRAViO mobile launcher

Installable home-screen launcher for the existing GRAViO showroom web app.

The approved white icon uses a black door, fine black GRAViO lettering and red accents. The launcher retains a black screen. It contains no credentials, customer records, inventory or financial data. The business application continues running on Google Apps Script.

Publish the root of the default branch with GitHub Pages. Open the published page in Safari, then Share → Add to Home Screen. Use `?install` to keep the instructions visible from an installed shortcut.

Installed mode navigates to the existing Apps Script deployment; browser behavior on cross-origin navigation can vary. This is a launcher, not a port of the Apps Script backend. No service worker or offline guarantee is added.
